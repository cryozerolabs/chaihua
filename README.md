# 拆画

想从海报里提取商品素材，或只调整标题、价格标签的位置，手里却只有一张 PNG 或 JPG：各个元素已经合在一起，修改和复用都需要重新抠图、修补背景。

拆画是一款 AI 图层拆分与编辑工具。生成或上传一张图片，拆出图层后直接移动、缩放、调整层级，把已有画面用于下一次创作。支持 **PNG 导出、单个素材透明 PNG 下载和 PSD 导出**。

## 使用流程

1. **放入原图**：在底部输入需求，点击“生成图片”；也可以点击“上传图片”，或将 PNG、JPG、WebP 拖入画布。
2. **拆分图层**：点击画布上的原图，再点击“拆分图层”。系统自动规划怎么拆，完成后在旁边新增图层组。

   ![画布上的原图与拆分后的图层组](docs/screenshots/canvas-overview.jpg)

   图示为经过追加拆分整理的结果。

3. **选择图层**：点击图层组，再点击画面中的某个素材，或右侧图层列表中的对应项，即可选中该图层。
4. **编辑图层**：拖动选中的图层改变位置，拉动四角等比缩放。拖动右侧列表项调整层级，也可以隐藏、锁定或解锁图层。拖动标题栏移动整个图层组；背景默认锁定。

   ![选中商品对应的图层，画布显示编辑边框，右侧列表同步选中](docs/screenshots/layer-editing.jpg)

5. **按需下载**：图层组工具栏提供“导出 PNG”和“导出 PSD”；右侧每个图层的下载按钮用于导出单个素材。

滚轮缩放画布，拖动空白处平移。编辑支持撤销、重做、对象删除和自动保存；刷新后恢复项目。项目与素材保存在本地 `.data/`，失败任务可在任务面板重试。

## 拆分结果

图层由模型生成，部分对象可能仍合在同一层，背景补全和边缘也可能与原图有差异。文字保留为图片图层，PSD 导出的是独立像素图层。

## 本地运行

需要 Node.js 22.12 或更新版本。

```sh
git clone https://github.com/cryozerolabs/chaihua.git
cd chaihua
npm install
cp .env.example .env
```

配置说明见 [.env.example](.env.example)。完成本地配置后启动：

```sh
npm run dev
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。修改 `.env` 后需要重启服务。

## 开发

前端使用 React、TypeScript、Vite 和 react-konva；后端使用 Node.js、Express、sharp 和 ag-psd。视觉模型规划拆层方案，拆层模型生成 RGBA 图层，本地代码负责编辑、合成和导出。

```sh
npm test
npm run build
npm start
```

生产构建后，默认在 [http://127.0.0.1:3001](http://127.0.0.1:3001) 提供网页与 API。接口定义见 [server/index.ts](server/index.ts)。
